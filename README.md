# PowerShell IT Projects

A collection of PowerShell scripts I built while learning and practicing PowerShell for my upcoming IT co-op.

## Projects

### PC Health Checker

`PC-Report.ps1`

Collects system information and checks:

* Memory
* Disk space
* Services
* Processes
* Installed applications

### Intune Readiness Checker

`Intune-readiness-checker.ps1`

Performs a basic readiness assessment covering:

* Windows compatibility
* PowerShell version
* Hardware requirements
* Network connectivity
* Windows Update
* Installed applications

## Purpose

These scripts are learning projects and are not intended to be production-ready tools. They were created to strengthen my PowerShell fundamentals and begin applying them to practical IT administration scenarios.

I plan to continue improving these scripts and expanding my knowledge of PowerShell, Windows administration, Intune, automation, and related technologies.
